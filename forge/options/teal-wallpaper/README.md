# teal-wallpaper

Teal-shag default wallpaper, baked into framework-res (`drawable-nodpi`, density PNGs dropped so
the one image is used everywhere).

`assets/default_wallpaper.{jpg,webp}` — original artwork by **TheDBP**, made for this project.
Licensed with the rest of rom-forge (Apache-2.0). Not taken from any stock firmware, which is why
the release audit's wallpaper check accounts for it by hash.
